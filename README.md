# Portifólio-nv

Site de portfólio em um único arquivo (`index.html`), com animações em GSAP 3.13 (ScrollTrigger, SplitText, ScrambleText) e rolagem suave com Lenis.

- **Ajustar o ritmo das animações:** objeto `MOTION` no topo do script (`ease`, `dur`, `stagger`, `scrub`).
- **WhatsApp:** troque o número em `WHATS` no script.
- **Publicação:** site estático na Vercel — cada push na `main` publica de novo.
